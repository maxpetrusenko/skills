# Platform Formatting

## Default Rule

Auto-detect formatting from the target platform.

If the target platform is not explicit, ask the user before finalizing the post.

## X / Twitter

- strongest first line
- shorter total length
- tighter rhythm
- 2 to 4 short blocks max
- one proof point is enough
- hashtags optional and sparse
- image, screenshot, or video should feel like proof

## LinkedIn

- keep the same core idea, but open up the explanation
- more room for builder context
- stronger use of whitespace
- external links are often better in first comment when reach matters

## Visual Asset Rule

- if the platform is image-friendly, prefer a real screenshot or demo still
- if the platform is link-first and the repo/demo is the real asset, prefer the URL
- generated images are fallback only

## Ask Rule

Ask the user when any of these are unclear:

- target platform
- publish now vs schedule
- which attached asset should be primary
- whether the post should be broad, technical, or more contrarian
