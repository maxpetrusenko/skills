# Composition rules, with the reasons

These come from Max's critique of the first reference set (rated 6.5/10: "readable, but they look like formatted summaries"). The one that worked was the Orca waveform, because you can see which state is playing before you read the label.

| Rule | Why |
| --- | --- |
| One close-up | Evidence is a few things in the same place. A stack of cards reads as a summary. |
| State in the same slot | A legend (two separate cards) makes the reader match words to shapes. Same slot, different contents, makes the difference the only thing that moves. |
| State visible before the label | Dashed line vs green waveform needs no caption. If the label is needed to tell them apart, the picture is not doing the work. |
| Each number once | The reference perf image printed 7-11 s in a chip and again on the bar. Twice means the picture is a table. Print it at the mark. |
| Dot = value, bracket = range | A range drawn as a dot is a different claim. |
| Lanes and axis only when timing is known | An axis implies durations. The Orca reply gave none, so the state key has no axis and no timing. |
| Bracket at the moment it becomes available | The wait is tied to the player: dashed until the bracket, waveform after. A number floating beside a bar is not tied to anything. |
| Highlight only the digits that changed | Whole-line highlights tell the eye nothing. "0.55" vs "0.549" differ in one digit. |
| Aligned numbers | Monospace columns, a dotted gap where the other line has no digit. |
| Light theme only | Standing rule. The dark Orca reference is rendered in the light palette. |
| Layered architecture, one direction | Real names, an icon on each node, labeled arrows top to bottom. No bare "Diagram" boxes, no crossing lines. |
| Headline states the conclusion | "The gate was right." beats "Gate threshold fix". Under nine words. |
| Footer states scope or limit | "Gate decision unchanged." Never repeats a caption. |

Dropped from the first draft: the lone metric card, numbered footer lines that repeated captions, empty whitespace under the content.
